# Guía de contribución

¡Gracias por tu interés en contribuir a **ia-tools**!

## Cómo contribuir

1. Haz un *fork* del repositorio y crea una rama descriptiva:
   ```bash
   git checkout -b feature/mi-herramienta
   ```
2. Añade tu herramienta en la carpeta correspondiente (`tools/`, `apps/`, `notebooks/`).
3. Incluye un `README` breve dentro de tu herramienta explicando:
   - Qué hace.
   - Cómo instalarla y ejecutarla.
   - Un ejemplo de uso.
4. Abre un *Pull Request* describiendo el cambio.

## Buenas prácticas

- No subas datos sensibles, credenciales ni información de pacientes.
- Documenta las dependencias (`requirements.txt`, `pyproject.toml`, etc.).
- Escribe código claro y comentado; prioriza la reproducibilidad.

## Código de conducta

Sé respetuoso y constructivo en todas las interacciones.
